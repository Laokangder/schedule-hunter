## 二、统一业务闭环

```text
通知监听 / Android 分享 / 手动输入
                ↓
           AI 解析与变更识别
                ↓
      候选持久化与相似候选合并
                ↓
候选收件箱 ── 编辑 / 忽略 / 稍后提醒
                ↓
         冲突检测与智能空档推荐
                ↓
        用户确认创建或更新日程
                ↓
 Android 本地提醒 + 系统日历同步
```

任何自动捕获内容都只能先生成候选。低置信度变更不会直接修改任务；创建、更新和取消正式日程都必须由用户确认。

## 三、统一候选数据模型

候选记录已保存：`candidate_id`、`request_id`、`dedup_key`、`intent_type`、`target_task_id`、`source_type`、`source_package`、`source_app_name`、`source_text`、`parsed`、`changes`、`confidence`、`match_confidence`、`status`、`snoozed_until`、`seen_count`、`sources`、`created_at`、`updated_at`。`snooze_notified_at` 用于保证到期候选只被领取一次。

合并规则已经落地：

1. 相同 `request_id` 幂等返回同一候选。
2. 相同原文指纹直接合并；每个被合并指纹都会持久化映射。
3. 标准化标题相同、开始时间相差不超过 10 分钟且地点相同或一方为空时，只合并 `pending/snoozed` 候选。
4. 合并会增加 `seen_count`、更新时间并追加来源。
5. 只有更高置信度的解析结果会替换主结果。
6. `confirmed/ignored` 候选不会被普通重复通知重新打开。

## 四、接口契约

| 方法 | 路径 | 状态与用途 |
|---|---|---|
| `GET` | `/api/v1/tasks/{task_id}` | ✅ 查询单个正式日程 |
| `PUT` | `/api/v1/tasks/{task_id}` | ✅ 部分更新标题、时间、地点、参与者、优先级和提醒策略 |
| `POST` | `/api/v1/candidates` | ✅ 幂等创建或合并候选 |
| `GET` | `/api/v1/candidates` | ✅ 按状态查询；`due=true` 原子领取已到期 snooze 候选 |
| `GET` | `/api/v1/candidates/{candidate_id}` | ✅ 查询候选详情 |
| `PATCH` | `/api/v1/candidates/{candidate_id}` | ✅ 编辑候选或设置 `pending/ignored` |
| `POST` | `/api/v1/candidates/{candidate_id}/confirm` | ✅ 事务内确认创建、更新或取消 |
| `POST` | `/api/v1/candidates/{candidate_id}/snooze` | ✅ 延后 10 分钟、1 小时或指定时间 |
| `POST` | `/api/v1/tasks/free-slots` | ✅ 根据正式日程、工作时段和缓冲推荐空档 |

统一约束已经落实：新写接口使用 `request_id` 幂等，继续使用 `BaseResponse`；不存在返回业务码 `4001`，非法时间返回 `2001`；SQLite 只增表、增列和增索引；SQL 参数化；日志不输出通知正文、`source_text`、LLM 原文或密钥。任务时间或提醒策略变化时会清空 `reminded_offsets`、将 `is_reminded` 重置为 `0`，成功后广播 `TASK_UPDATED`。

## 五、数据库向前兼容变更

- `tasks`：缺失时追加 `updated_at`，不删除或重建用户表。
- `candidates`：保存候选主记录、解析结果、变更、来源、状态和 snooze 去重字段。
- `candidate_requests`：保存所有进入合并候选的 `request_id` 映射。
- `candidate_dedup_keys`：保存所有进入合并候选的原文指纹映射，保证终态重复通知仍命中原候选。
- `idempotency_operations`：保存任务更新、候选确认和 snooze 等写操作结果。
- 为状态、更新时间、意图、到期时间、请求映射和指纹映射建立索引。
