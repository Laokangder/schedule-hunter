```javascript
function isExpired(task) {
  if (task.status === 'expired') return true
  if (!task.start_time) return false
  const now = Date.now()
  const startTime = new Date(task.start_time).getTime()
  const endTime = task.end_time ? new Date(task.end_time).getTime() : startTime + 3600000
  return endTime < now
}
```

**useTaskStore.js (_schedule_reminder)：**
```javascript
_schedule_reminder(task) {
  if (!task?.start_time) return
  const now = Date.now()
  const start = new Date(task.start_time).getTime()
  const diff = start - now
  if (diff <= 0) {
    this.active_task = task
    this.island_state = 'reminder'
  } else if (diff <= this.reminder_threshold) {
    this.active_task = task
    this.island_state = 'tracking'
  } else {
    this.active_task = task
    this.island_state = 'tracking'
  }
}
```

**架构定义四态：**

| 状态 | 架构定义 | 实际实现 |
|------|----------|----------|
| 静默 (Silent) | 胶囊最小化、低对比度中性色 | ✅ ScheduleIsland idle 状态 |

**状态切换规则实现差异：**

架构设计：
```
静默 ──存在临近任务──▶ 倒计时 ──进入提醒阈值──▶ 任务提醒
  ↑                              │
  │                              ↓
  └──────用户修正完成─────── 冲突预警
```

实际实现（useTaskStore.js）：
- `_schedule_reminder` 方法实现了部分状态流转
- 但状态命名使用 `islandState`（大写），与 store 定义 `island_state`（小写）不一致
- ScheduleIsland 组件中使用了 `store.islandState`（大写），与 store 定义冲突

| 错误码 | 含义 | 前端处理建议 |
|--------|------|-------------|
| 1001 | 解析文本为空 | 提示用户输入日程内容 |
| 1002 | 时间表达式无法识别 | 提示用户补充具体时间 |

- mockProvider.js 无错误模拟
